# いえこと

家の「あれやらなきゃ」を、忘れない。家族で使う、家のやることリスト。

内部は仕事のIssueと同じ形（担当・期限・履歴・繰り返し）を持ちますが、画面には出しません。
出るのは **ホーム / 追加 / 詳細 / おわったもの** と、世帯のシートだけです。

変更は上書きせず、**op（操作ログ）として追記**します。いまの状態は、opの列を突き合わせて射影した結果です。
これで、定期の次の1件も取り消しも、どの端末でも同じ結果になる（[docs/SYNC_DESIGN.md](docs/SYNC_DESIGN.md)）。

## 何をするアプリか

- 気づいたときに、タイトルだけで放り込める（登録は3秒。担当も期限も後でよい）
- 終わったら丸を1タップ。間違えたら数秒その場で取り消せる
- **定期の案件は、終わらせると次の1件が自動で出てくる**（毎日／毎週◯曜／終わってからN日ごと）
- **終わった記録は自動で溜まる**。数年住むと同じ案件の前回・前々回がそのまま家の記録になる
- 詳細の下は、コメント欄ではなく家族のやりとりとして読める形（写真・担当の変更・「対応待ち」も同じ並びに入る）

やらないこと: 分担のグラフ、ポイント、ランキング、時給換算、達成率、家計簿、カレンダー、買い物専用画面、広告。

## 同期（2台以上で同じ家のものを見るとき）

**1人で使うなら、何も要りません**（サーバーに一切つながりません）。2台以上で共有したいときだけ、
同期サーバー（Cloudflare Workers + D1）を立てて、ビルドのときに世帯idとトークンを渡します。

```bash
cd server && npm run serve -- --port 8799      # 手元で試す（Cloudflareのアカウントは要らない）
flutter run -d web-server --web-port 8080 \
  --dart-define=IE_KOTO_API=http://127.0.0.1:8799 \
  --dart-define=IE_KOTO_HOUSEHOLD=hh_wagaya00000000000000000000000000 \
  --dart-define=IE_KOTO_TOKEN=8f3c1d5e7a9b2c4d6e8f0a1b3c5d7e9f2a4b6c8d0e
```

同じ2つの値を別の端末で使えば、同じ世帯になります。opの出し入れ2本に、世帯の始末2本を足した計4本で、基本の2本のやることは
「op（操作ログ）を預かって、挿入順に返す」だけです（[server/README.md](server/README.md)）。
世帯の作り方と本番の置き方は [docs/SYNC_DESIGN.md](docs/SYNC_DESIGN.md) §3・§5。

ホーム右上の世帯名を押すと、画面から世帯を作る・参加する・招待文を送る・トークンを作り直す・世帯を消すができます。
`--dart-define` で渡す方法も残っています（渡したものが最優先）。
渡した・作った世帯idとトークンは端末に残るので、**次の起動からは付け直さなくてよい**です
（cursor も残るので、もらうのは前回からの差分だけ）。

### 相手がアプリを入れていないとき（1件リンク）

詳細の「そのほか」→「リンクを送る」を押すと、その1件のURLがコピーされます。LINEでもメールでも、
それを送るだけ。相手は**ブラウザで開いて、中身を見て「やる」を押せます**（アプリのインストールもアカウントも不要）。

```
https://<アプリとAPIのドメイン>/#one?i=<案件id>&h=<世帯id>&t=<世帯トークン>&m=<メンバー>
```

- 相手に渡るのは**その1件のopだけ**。世帯のほかの案件は、画面にも通信にも入りません
- 相手のブラウザには**何も残しません**（端末idも保存しないので、開くたびに新しくなります）
- 世帯トークンはURLの **`#` の後ろ**（断片）に入ります。断片はサーバーに送られないので、アクセスログに鍵が残りません
- 「やる」は担当を引き受ける `assignee` opを1つ書いて、その場で送ります。送れなかったときは書いたまま残り、押し直しでは**opを増やさずに送り直します**
- リンクには7日の期限が付きます。過ぎたリンクを開いても、ただのアプリになります

設計と検証の記録は [docs/SYNC_DESIGN.md](docs/SYNC_DESIGN.md) §2・§8.6、[docs/VERIFICATION.md](docs/VERIFICATION.md)。

この版は**保存します**。op（操作ログ）と端末idは端末に残り、閉じても消えません（手順1・完了）。
**初回だけ**、よくある家庭の案件（牛乳・保育園の書類・ゴミ出し・エアコン・電球・水道・子供の靴・お風呂そうじ）が入った状態で始まります。
次に開いたときは、その続きから始まります（デモを入れ直しません）。

## 画面は4つ＋世帯のシートだけ

| 画面 | 出るもの | 主な操作は1つ |
|---|---|---|
| ホーム | 「今日」と「あとで」。1行は最大2行（タイトル＋情報は最大2つ）。要るときだけお知らせ1行 | 追加 |
| 追加 | 何する？／だれ／いつ。**打ってEnterで登録完了** | 追加 |
| 詳細 | だれが・いつまで・くりかえし（畳んである）／これまで／ひとこと | おわった |
| おわったもの | これまで終わったもの（新しい順） | 見るだけ |
| 家族とつなげる | ホーム右上の世帯名から開く。世帯の作成・参加・招待・再発行・削除／この端末の人と表示名／記録の書き出し・読み込み | つくる・はいる |
