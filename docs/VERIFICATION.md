## 目視で確認した画面

- **ホーム**: 「家のこと／わが家」「今日 4」「あとで 4」、1行は「丸 + タイトル + 情報」で情報は最大2つ（例: `今日・自分`、`10/9・終わってから60日ごと`）
- **追加**: 1行の入力＋追加、だれ（だれでも／自分／パートナー）、いつ（なし／今日／明日／今週末）。打ってEnterで登録され、入力欄は空になって続けて入れられる。追加した行まで自動で送る
- **詳細**: だれが／いつまで／くりかえし の3行（畳んである）、これまで（時刻つきの並び・写真枠・担当変更）、下に「ひとこと」と丸い完了ボタン

## エミュレータで操作して確認したこと

Pixel 6（API 35）のエミュレータにデバッグビルドを入れ、`adb` でタップと入力をして確認した（同期は有効にしていない）。日本語は、エミュレータの Gboard に日本語（QWERTY・ローマ字入力）を追加して、`adb input text` でローマ字を1文字ずつ送って打った。ログに例外やオーバーフローは出なかった。

- **完了した行は元の位置に残る**: 「牛乳を買う」の丸をタップすると、取り消し線と「おわった」「もどす」付きで、元の3番目の位置に残った。「今日」の件数は4から3に減った。約6秒後に一覧から消えた
- **連続して追加できる**: `later1`〜`later8` を続けて追加。入力欄は空になり、最後に追加した行まで自動で送られた
- **今日に追加した行が見える**: 一覧が長い状態で「今日」を選んで追加すると、上の「今日」の位置まで送られ、追加した行が画面内に入った
- **消すときは確かめる**: 詳細の「そのほか」から「消す」を選ぶと「「◯◯」を消しますか？」が出る。「やめる」で詳細に残り、「消す」で一覧から無くなった
- **日本語で追加できる**: `tamagowokau` を打つと「たまごをかう」が下線付きの変換中表示になり、確定して「追加」を押すと一覧に入った。入力欄は空に戻り、追加した行まで送られた。詳細の見出しも崩れず表示された
- **日本語でひとことを送れる**: 詳細で `kyouwakaimono` を打って送ると、履歴に「きょうわかいもの／自分」が出た
- **見つかった不具合（修正済み）**: 詳細で「ひとこと」をタップしてキーボードを出すと、入力欄と完了ボタンがキーボードの下に隠れていた。バーをキーボードの高さぶん持ち上げて直し、エミュレータで入力欄が見えることを確認した（キーボードの Enter が「送信」の矢印になることも確認）
